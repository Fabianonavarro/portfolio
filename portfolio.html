Dashboard de Vendas — XBOX Game Pass

Análise e Visualização de Dados em Excel

O objetivo deste desafio é criar um dashboard de vendas utilizando dados de assinaturas do Xbox Game Pass. O projeto transforma dados brutos em informações visuais claras e úteis, permitindo análise eficaz do desempenho de vendas e suporte à tomada de decisões.

  • Ferramenta: Microsoft Excel
  • Metodologias aplicadas: Método ABCDE, gráficos dinâmicos, Big Numbers, Data View, organização e estilização do dashboard
  • Conteúdo: Dados base e arquivo final com dashboard (.xlsx)
  • Link: Código e arquivos no GitHub

Análise de Dados de COVID-19 🦠📊

Visualização e Previsão com Python e Streamlit

Projeto que utiliza Python para analisar e visualizar dados relacionados à pandemia de COVID-19 no Brasil, oferecendo insights sobre a evolução dos casos e previsões futuras.

  • Funcionalidades: Carregamento de dados, filtragem, visualização de casos e mortes, previsões com ARIMA e Prophet, decomposição de séries temporais.
  • Tecnologias: Python, Pandas, NumPy, Plotly, Matplotlib, Statsmodels, Pmdarima, Prophet, Streamlit
  • Como rodar:
    1. Digite no terminal: streamlit run analise_covid19.py
    2. Ou execute: executa.bat
  • Link: Código no GitHub
